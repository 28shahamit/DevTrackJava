# DSA Roadmap Import

Use **Learn → Import Roadmap JSON** and select `DSA-ROADMAP-IMPORT.json`, or use the bundled DSA starter from the Learn screen.

The DSA roadmap is question-oriented and uses the same dynamic roadmap engine as Java Backend.

Every question may contain:

- `url`: one primary coding problem URL
- `links`: multiple named URLs
- `difficulty`
- `priority`
- `interview`
- `tags`
- completion state

The UI exposes DONE, OPEN, SAVE, LATER and TRACK actions when applicable.
